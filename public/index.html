Mass import profiles
Bot files from Valor, Hayha, Stellar, Shikari and AYCD are recognized automatically: load the file or paste its contents. Profiles with the same name in the chosen category are updated instead of duplicated.

For spreadsheets, headers are matched loosely ("First Name", "Address", "ZIP", "Card Number", "CVV", "Exp" as MM/YY all work). Missing billing columns = billing same as shipping. A category column puts each row in that category.
Bulk edit
Tokens: {n} numbers profiles in order · {r:1-999} random number · {name} {first} {last} pull from each profile. Example: {first}.{last}{r:10-99}@yourdomain.com
