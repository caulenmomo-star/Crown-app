Get Crown Tools

One app on your iPhone, iPad, Mac and PC — same account and data everywhere, and it updates itself.

This device

    Open in the browser instead

    ✓ Crown Tools is already installed on this device. Open it from your home screen, Dock or Start menu.

    iPhone & iPad

    1. Open in Safari.
    2. Tap the Share button (square with an arrow).
    3. Tap Add to Home Screen, then Add.
    4. Open Crown Tools from your home screen — full screen, like any app.

    Mac

    1. Chrome or Edge: open and click the install icon at the right end of the address bar (or Install on this page).
    2. Safari: choose File → Add to Dock…
    3. Crown Tools opens in its own window from the Dock and Launchpad.

    Windows PC

    1. Open in Chrome or Edge.
    2. Click the install icon at the right end of the address bar (or Install on this page).
    3. Crown Tools gets its own window and appears in the Start menu and taskbar. Pin it if you like.

    Android

    1. Open in Chrome.
    2. Tap ⋮ then Install app.
